🌐 What is SeaRouter?

SeaRouter 是下一代大模型统一接入基础设施。我们不仅仅是一个聚合全球顶尖 LLM（如 OpenAI, Claude, DeepSeek, 智谱 GLM）的高速中转站，更是连接公有云智能与私有化算力的弹性桥梁。

在 AI 落地过程中，开发者往往面临艰难的选择：是使用公有云模型的强大通用能力，还是为了数据安全和成本选择本地部署？

SeaRouter 的答案是：Why not both? 我们为您提供统一的 OpenAI 兼容接口，让您的应用能够在"云端大模型"与"本地私有模型"之间自由切换、混合调用。

⚡ Core Features

☁️ 全球模型中转

Global Model Relay - 如同 OpenRouter 一样，我们提供标准化的 API 聚合服务。

  • 一站式接入：一个 API Key 即可调用 GPT-4o, Claude 3.5, Gemini 1.5 Pro 以及 GLM-4, DeepSeek, Llama 3 等开源模型
  • 企业级稳定性：全球多节点加速，智能负载均衡，确保 99.9% 的 API 可用性
  • 透明计费：实时竞价路由，帮助您以最低成本获得最佳效果

🔒 自托管与本地融合

On-Premise Integration - SeaRouter 的独特基因，无缝接入您的私有算力。

  • BYOC：本地 NVIDIA 集群或私有云 vLLM 实例，都可以注册为后端节点
  • 数据驻留：通过路由规则引擎，强制将敏感数据仅路由至本地模型
  • 零代码适配：原生支持 Ollama, TGI, vLLM 等主流推理框架

🔀 弹性路由引擎

Smart Flex Routing - 定义您的流量策略，剩下的交给我们。

  • 混合编排：简单问题交给本地模型（免费），复杂逻辑交给云端大模型（付费）
  • 故障转移：当本地 GPU 显存占满时，自动溢出至公有云模型
  • 负载均衡：多渠道智能分发，保障服务不中断
